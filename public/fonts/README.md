# Fonts

Place the following woff2 font files in this directory:

- `BebasNeue-Regular.woff2` — Bebas Neue (display/headings)
- `DMSans-Variable.woff2` — DM Sans variable font (body text)
- `JetBrainsMono-Variable.woff2` — JetBrains Mono variable font (monospace/terminal)

These fonts are not committed to the repository. Download them from their respective sources:

- Bebas Neue: https://fonts.google.com/specimen/Bebas+Neue
- DM Sans: https://fonts.google.com/specimen/DM+Sans
- JetBrains Mono: https://fonts.google.com/specimen/JetBrains+Mono
